Provenance & editability legend

The four things you listed aren't one scale — they're two axes. Where a number came from (document, user, model, another module) is origin. Whether you can change it is editability. Encoding them on one swatch is why data keys usually fail: a calculated number can be overridden, a document number can be locked. Colour carries origin, typography carries editability, and one flag layer carries "needs review".

Three ways to render it — same rows, same data

Pick one and use it everywhere. My recommendation is A: the dot is a fixed 9px cost regardless of density, survives bold totals and red negatives, and leaves value colour free for financial meaning (negatives, deltas) — which B spends on provenance.
